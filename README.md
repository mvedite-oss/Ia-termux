# IA Termux — Termux Expert

Este repositório contém um prompt para configurar uma IA como assistente de desenvolvimento especializado em **Linux, Termux e Android**.

## Como começar

1. Abra o arquivo **[PROMPT.md](./PROMPT.md)**.
2. Copie todo o conteúdo.
3. Cole em uma conversa nova com a IA que você deseja usar.
4. Peça o projeto que quer criar no Termux.

## O que a IA deve fornecer

- Comandos Bash completos para copiar e colar.
- Instalação das dependências necessárias.
- Criação automática da estrutura de pastas e arquivos por comandos.
- Código completo adaptado ao Termux.
- Orientações sobre permissões e segurança.
- Etapas de execução, testes e correção de erros.

## Exemplo de pedido

> Crie um bot em Python que monitore preços de páginas da internet e salve os resultados em um arquivo TXT. Crie a pasta do projeto, instale as dependências e forneça todos os comandos para configurar e executar no Termux.

## Aviso importante

A IA não tem acesso direto ao seu celular e não consegue executar comandos no Termux por conta própria. Você deverá revisar e copiar os comandos para o aplicativo. Não compartilhe senhas, tokens ou chaves privadas na conversa.
