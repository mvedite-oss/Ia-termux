# Exemplos de solicitações

Use estes exemplos depois de enviar o conteúdo de `PROMPT.md` para a IA.

## 1. Criar um painel em Python

"Crie um painel de terminal em Python para o Termux, com menu interativo. Prepare as pastas, instale as dependências, crie todos os arquivos e mostre como executar."

## 2. Criar um site local

"Monte um site com HTML, CSS e JavaScript que eu consiga abrir no navegador do celular. Gere os arquivos e explique como iniciar um servidor local no Termux."

## 3. Instalar um projeto do GitHub

"Quero baixar e configurar este projeto do GitHub no Termux. Verifique os requisitos, instale as dependências e me passe os comandos em ordem. Explique qualquer comando que possa apagar ou alterar arquivos."

## 4. Corrigir um erro

"Vou enviar a mensagem de erro e os comandos que executei. Analise o problema, explique a causa provável e me dê os comandos corrigidos para testar no Termux."

## 5. Criar uma ferramenta por etapas

"Quero criar uma ferramenta nova no Android usando Termux. Divida o trabalho em preparação, estrutura de pastas, implementação e teste."
